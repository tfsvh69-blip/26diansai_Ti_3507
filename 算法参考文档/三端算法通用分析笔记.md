# 三端算法通用分析笔记（硬件平台无关版）

> 本文只讨论算法结构、数据流和设计取舍，不绑定任何具体主控、处理器、传感器或开发板型号。
> 后续迁移到其他硬件平台时，应根据算力、采样率、传感器噪声、执行机构和实际场景重新整定参数。

---

## 0. 总体思路：按算力和实时性分层

多处理器系统中，算法不应平均分配，而应根据各端的任务特点进行分层：

| 功能端 | 平台特点 | 适合承担的算法 | 设计重点 |
|---|---|---|---|
| 视觉端 | 计算能力较强，允许较高延迟 | 图像预处理、目标检测、几何校正、测距、误差计算 | 鲁棒性和识别精度 |
| 姿态与决策端 | 实时性和算力较均衡 | 姿态融合、卡尔曼滤波、状态机、跟踪控制 | 精度、稳定性和任务协调 |
| 运动执行端 | 资源受限、控制周期严格 | 传感器归一化、轻量姿态解算、低通滤波、串级控制 | 实时性、确定性和易调试性 |

通用数据流可以概括为：

```text
运动执行端：
传感器数据 → 循迹/姿态估计 → 运动控制 → 执行机构
          └→ 状态、进度、转弯信息 ───────┐
                                          ▼
视觉端：                                  姿态与决策端：
相机图像 → 目标检测 → 位置误差 ─────────► 数据融合 → 状态机 → 目标姿态
                                          ▲              │
自身惯性传感器 → 姿态估计 ────────────────┘              ▼
                                                     云台或其他执行机构
```

核心原则是：

- 计算量大的感知算法放在高算力端。
- 高频闭环控制放在实时性更强的控制端。
- 资源受限端优先采用固定计算量、低内存占用、可预测执行时间的算法。
- 决策层只接收已经提炼过的状态量，不直接处理所有原始数据。

---

# 第一部分：运动执行端算法

## 1.1 多路传感器循迹：归一化加权误差

### 要解决的问题

一排传感器会同时输出多个强度值，需要将这些离散数据转换成连续的横向偏差，供方向控制器使用。

直接采用“哪个传感器检测到目标就输出哪个位置”的方法，会导致误差只有少数几个档位，车辆容易在目标线附近反复抖动。

### 通用思路

先给不同位置的传感器分配权重，再计算左右或整体的加权中心：

```text
位置误差 = Σ(传感器值 × 位置权重) / Σ(传感器值)
```

也可以采用左右差比和形式：

```text
误差 = (左侧加权量 − 右侧加权量) / 全部传感器总量
```

其中：

- 越靠外侧的传感器，位置权重绝对值越大。
- 分子反映偏向哪一侧以及偏离程度。
- 分母用于归一化，减小环境亮度、反射强度和目标宽度变化带来的影响。
- 当分母过小时，应判定为目标丢失，而不是继续做除法。

### 传感器校准

不同通道的零点和满量程通常不一致，可先做线性归一化：

```text
归一化值 = (当前值 − 背景值) / (目标值 − 背景值)
```

背景值和目标值应通过现场标定获得，并对结果进行限幅。

### 适用性

该算法只需要少量加减乘除，计算复杂度与传感器数量成线性关系，适合资源受限、控制周期严格的平台。

### 注意事项

- 目标完全丢失时，不应简单把误差设为零，否则控制器可能误认为已经对准。
- 更合理的处理是保留最后方向、进入搜索模式，或根据状态机采取减速和回退。
- 误差中存在尖峰时，可增加低通滤波，但滤波不能过重，否则会引入明显转向延迟。

## 1.2 惯性姿态估计：轻量互补融合

### 要解决的问题

惯性传感器通常提供三轴角速度和三轴加速度。角速度积分短期平滑，但会累积漂移；加速度可以提供重力方向参考，但容易受到振动和运动加速度干扰。

### 互补融合的核心

轻量姿态算法的基本思想是：

- 高频、短时间变化主要相信陀螺仪。
- 低频、长期趋势使用重力方向进行缓慢校正。

一种常见实现流程如下：

1. 对加速度向量进行归一化。
2. 根据当前姿态估计机体坐标系下的重力方向。
3. 将估计重力方向与实测重力方向做叉积，得到姿态误差方向。
4. 用比例项或比例积分项修正角速度。
5. 使用修正后的角速度更新四元数。
6. 对四元数归一化，并按需要转换为欧拉角。

### 为什么使用四元数

四元数相比直接对欧拉角积分具有以下优势：

- 避免部分姿态下的奇异问题。
- 连续旋转时数值表现更稳定。
- 旋转组合和姿态更新更方便。

### 偏航角连续化

欧拉偏航角通常限制在一个固定范围内，跨越边界时会突然跳变。若需要累计转角，应检测相邻两帧的跨界跳变，并维护圈数：

```text
连续偏航角 = 当前偏航角 + 圈数 × 一周角度
```

该处理适用于直角转弯、连续绕圈和角度锁定。

### 局限

仅依靠陀螺仪和加速度计时，重力方向无法提供绝对偏航参考。因此，偏航角长期仍可能漂移。若任务需要长期绝对航向，应增加磁场、视觉、里程计或其他外部参考。

---

## 1.3 快速归一化：平方根倒数近似

姿态算法中经常需要计算：

```text
1 / √x
```

它通常用于向量和四元数归一化。资源受限平台可以采用近似初值加一次或多次牛顿迭代：

```text
y(n+1) = y(n) × (1.5 − 0.5 × x × y(n)²)
```

### 设计取舍

- 迭代次数越多，精度越高，但计算量也更大。
- 对姿态归一化而言，一次迭代通常已经能够满足实时控制需要。
- 在具有高效硬件开方指令的平台上，应实际测试近似算法与标准数学库的速度和误差，不必机械沿用旧式优化。

## 1.4 二阶 IIR 低通滤波

### 用途

电机振动、机械冲击和路面颠簸会在加速度、角速度及循迹误差中引入高频噪声。二阶 IIR 滤波器可以用很少的状态量实现较好的低通效果。

通用差分方程为：

```text
y[k] = b0·x[k] + b1·x[k−1] + b2·x[k−2]
       − a1·y[k−1] − a2·y[k−2]
```

### 优点

- 只需保存少量历史输入和输出。
- 每次计算只包含固定数量的乘加运算。
- 截止频率和品质因数具有明确的物理意义。
- 相比长窗口滑动平均，内存占用更小。

### 参数选择原则

- 截止频率应高于有效运动频率，低于主要噪声频段。
- 采样率变化后必须重新计算滤波器系数。
- 滤波过强会增加相位滞后，导致控制反应变慢。
- 不同信号应使用不同截止频率，不能用一组参数处理所有通道。

---

## 1.5 串级控制：位置或角度外环 + 速度内环

运动方向控制可采用串级结构：

```text
外环：方向误差或角度误差 → 目标角速度
内环：目标角速度 − 实际角速度 → 左右执行量差值
```

### 为什么采用双环

单环直接把位置误差映射为执行量，容易受到负载、摩擦和电机差异影响。串级控制把问题拆分为：

- 外环决定“希望以多快的速度纠正方向”。
- 内环保证“实际转向速度跟上目标”。

这样可以降低外部扰动对位置环的影响，并提高参数整定的可解释性。

### 常见保护措施

- 误差限幅，防止异常测量造成极端输出。
- 积分限幅，避免执行器饱和后积分继续累积。
- 输出限幅，匹配执行器真实能力。
- 变化率限制，降低目标或输出突变造成的机械冲击。

### 工程注意

变化率限制最好集中在明确的一层实现。若误差、控制器输出和最终执行量都分别限速，会造成响应迟钝，并使调参关系难以判断。

---

## 1.6 转弯状态机

对于规则路径，可将转弯过程拆分为多个状态：

```text
正常循迹
  ↓ 检测到转弯特征
进入转弯准备
  ↓ 延时或走到合适位置
角度锁定转弯
  ↓ 达到目标角度
重新进入正常循迹
```

### 设计意义

- 传感器在直角弯或交叉区域可能短暂失效。
- 进入转弯后，可暂时使用惯性角度作为主要反馈。
- 每个阶段使用不同的目标、限幅和速度设置，逻辑比大量条件判断更清晰。

### 需要设置的保护

- 每个状态应设置超时，防止传感器异常后永久卡住。
- 转弯完成条件应带滞回或连续满足若干周期，避免边界抖动。
- 状态切换时应清理或重置不再适用的积分量和历史误差。

---

## 1.7 运动进度估计

### 开环时间估计

最简单的方法是假设速度恒定，根据运行时间估算路径进度：

```text
进度增量 = 固定速度假设 × 控制周期
```

这种方法实现简单，但会受到加减速、打滑、转弯耗时和负载变化影响，误差会不断累积。

### 更可靠的闭环估计

优先级由高到低可考虑：

1. 编码器累计里程。
2. 视觉或地标定位。
3. 惯性与编码器融合。
4. 按路径关键事件进行分段校正。
5. 时间估计作为最后的退化方案。

若进度将用于周期轨迹相位、画圆、同步动作或精确触发，应该使用实际里程或可校正的闭环估计。

---

## 1.8 资源受限端的算法选择原则

| 算法类型 | 适用评价 |
|---|---|
| 归一化加权循迹 | 计算量小，适合高频执行 |
| 轻量互补姿态融合 | 固定计算量，适合只需相对姿态的场景 |
| 二阶 IIR | 内存和计算开销低 |
| 串级 PID | 结构清晰、实时性强 |
| 纯时间进度估计 | 实现简单，但长期精度较差 |

设计重点不是追求最复杂的算法，而是在控制周期内稳定完成计算，并给调试留出足够余量。

# 第二部分：姿态与决策端算法

## 2.1 四元数扩展卡尔曼滤波

### 核心思想

扩展卡尔曼滤波适合处理非线性姿态系统。它通常包含：

- 姿态四元数状态。
- 陀螺仪零偏或其他慢变量。
- 状态协方差矩阵。
- 过程噪声和观测噪声模型。

滤波过程分为预测和更新两部分：

```text
预测：由角速度推算下一时刻姿态
更新：使用重力方向等观测修正预测结果
```

与固定增益互补滤波相比，扩展卡尔曼滤波会根据当前不确定度动态调整融合权重，并可在线估计传感器零偏。

### 异常观测抑制

实际运动中，加速度计测到的不一定只有重力。碰撞、快速启停和机械振动都可能造成异常观测。可采用以下方法提高鲁棒性：

- 残差门限。
- 卡方检验。
- 自适应调大量测噪声。
- 异常时只预测、不更新。

### 偏航可观性

仅使用重力方向作为观测时，绕重力轴旋转不会改变加速度方向，因此绝对偏航不可观。算法应避免用加速度错误修正偏航，并在需要绝对航向时引入额外传感信息。

### 适用条件

该算法涉及矩阵运算、雅可比矩阵和矩阵求逆，适合算力较强、需要高精度姿态和在线偏置估计的平台。

---

## 2.2 通用卡尔曼滤波框架

线性卡尔曼滤波的标准过程可写为：

```text
1. 状态预测：      x⁻ = F·x + B·u
2. 协方差预测：    P⁻ = F·P·Fᵀ + Q
3. 卡尔曼增益：    K  = P⁻·Hᵀ·(H·P⁻·Hᵀ + R)⁻¹
4. 状态更新：      x  = x⁻ + K·(z − H·x⁻)
5. 协方差更新：    P  = (I − K·H)·P⁻
```

### 工程化设计建议

- 将矩阵维度、状态转移和观测模型配置化。
- 为不同状态设置最小方差，防止滤波器过度自信。
- 对异步传感器，只在新观测到达时更新对应量测。
- 允许在标准步骤之间加入用户回调，以扩展为非线性滤波或特殊约束模型。
- 对矩阵求逆失败、协方差非正定和数值发散设置检测与恢复机制。

---

## 2.3 视觉误差的匀速模型滤波

视觉处理频率通常低于控制频率，并可能存在抖动、延迟和丢帧。可以为横向和纵向误差分别建立二维状态：

```text
状态 = [位置误差, 误差变化速度]
```

采用近似匀速模型：

```text
位置(k+1) = 位置(k) + 速度(k) × dt
速度(k+1) = 速度(k)
```

### 作用

- 平滑视觉误差。
- 估计误差变化速度。
- 在短暂丢帧时进行外推。
- 对视觉延迟做一定程度补偿。

### 注意事项

- `dt` 应使用真实帧间隔，而不是固定常数。
- 长时间丢帧时，预测不应无限继续，应进入保持、减速或重新搜索状态。
- 过程噪声决定滤波器对快速运动的跟随能力，量测噪声决定对视觉数据的信任程度。

---

## 2.4 模块化 PID 控制器

通用控制器可将以下功能做成独立开关：

| 功能 | 作用 |
|---|---|
| 梯形积分 | 提高离散积分精度 |
| 变速积分 | 误差大时减弱积分，误差小时消除静差 |
| 微分先行 | 避免目标突变引起微分冲击 |
| 微分滤波 | 降低测量噪声对微分项的放大 |
| 积分限幅 | 防止积分饱和 |
| 输出滤波 | 平滑最终控制量 |
| 堵转或失效检测 | 识别长期不收敛状态 |

### 时间步长

积分和微分最好使用实际测得的时间间隔。控制周期存在抖动时，假设固定 `dt` 会造成增益等效变化。

### 调参顺序

1. 先关闭积分和微分，仅调整比例项。
2. 增加微分抑制振荡和超调。
3. 最后增加少量积分消除稳态误差。
4. 每次只修改一类参数，并记录响应曲线。

---

## 2.5 视觉误差到目标姿态的控制链

通用链路可以写成：

```text
原始视觉误差
  → 合理限幅
  → 滤波与短期预测
  → 跟踪控制器
  → 距离或尺度补偿
  → 目标姿态增量
```

### 距离自适应增益

同样大小的像素误差，在不同距离下对应的视角和实际位移不同。可以根据目标距离、目标框尺寸或标定尺度动态调整控制增益：

```text
实际控制增益 = 基础增益 × 距离补偿系数
```

补偿函数可以是线性映射、分段函数或通过标定表插值获得。

### 更通用的替代方案

若相机内参已知，可以先把像素误差转换为视线角误差，再交给角度控制器。这样比经验距离映射更容易迁移到不同分辨率、镜头和安装位置。

---

## 2.6 决策状态机

多任务系统应将“做什么”和“怎么执行”分离：

```text
输入：任务编号、运动状态、视觉状态、姿态状态、超时信息
  ↓
任务状态机
  ↓
输出：搜索、跟踪、转向、保持、执行动作等目标
```

### 推荐的分层方式

- 顶层任务状态：决定当前任务流程。
- 子状态：描述等待、搜索、对准、执行、完成和故障。
- 底层控制器：只负责跟踪目标，不参与任务逻辑。

### 状态机设计原则

- 每个状态明确进入条件、退出条件和超时条件。
- 使用枚举表示状态，避免魔数。
- 状态切换动作集中处理，例如清积分、重置计时器、初始化目标。
- 异常状态应有统一恢复路径。

# 第三部分：视觉端算法

## 3.1 图像预处理

可组合使用以下步骤：

```text
灰度化
  → 自适应或固定阈值分割
  → 形态学处理
  → 边缘检测
  → 区域与边缘信息融合
```

### 双通道融合

- 阈值分割保留目标区域，但容易受光照影响。
- 边缘检测保留轮廓，但容易受到纹理和噪声干扰。
- 将两者融合，可以同时利用区域和边界信息。

### 形态学闭运算

闭运算先膨胀再腐蚀，适合：

- 填补小缺口。
- 连接被高亮点或反光打断的边框。
- 平滑轮廓边缘。

结构元素尺寸必须与图像分辨率和缺口尺度匹配。固定大核在更换相机分辨率后可能失效，建议按目标尺寸比例设置。

---

## 3.2 矩形或规则目标检测

一个稳健的规则目标检测流程通常包含：

1. 面积和周长粗筛，去除小噪声。
2. 多边形近似，寻找四边形候选。
3. 检查角度、边长、长宽比和凸性。
4. 根据轮廓层级或几何包含关系寻找嵌套结构。
5. 对候选进行综合评分，选择最合理目标。

### 多策略兜底

实际图像中，轮廓层级可能因断边、反光或遮挡失效。可依次使用：

- 轮廓父子关系。
- 几何包含关系。
- 面积比例和中心距离。
- 历史帧位置预测。

高算力平台可以通过增加候选验证换取鲁棒性，但应设置合理上限，避免在噪声图像中产生大量候选。

---

## 3.3 角点排序

透视变换要求四个源角点与目标角点顺序一致。常见排序方法包括：

- 按坐标和与坐标差判断四角。
- 先按纵坐标分上下，再按横坐标分左右。
- 根据重心计算每个点的极角并排序。

排序完成后，应检查多边形方向和边是否交叉，防止角点顺序错误导致图像翻转或扭曲。

---

## 3.4 透视变换

斜视条件下，平面矩形会投影为一般四边形。可以通过单应矩阵将其校正到标准平面：

```text
目标点 ≈ H × 原图点
```

### 作用

- 将斜视目标拉正。
- 统一目标区域的像素尺度。
- 简化后续中心、尺寸和偏差计算。
- 便于在物理坐标与像素坐标之间转换。

### 注意事项

- 单应变换适用于近似平面目标。
- 角点误差会被变换放大，因此应先提高角点检测精度。
- 若需要从校正图映射回原图，应保存逆变换矩阵。

---

## 3.5 基于目标尺度的单目测距

若目标实际尺寸固定，图像中的面积或边长会随距离变化。面积法的基本关系为：

```text
距离 ≈ 参考距离 × √(参考面积 / 当前面积)
```

### 优点

- 计算量小。
- 不需要双目相机或额外深度传感器。
- 适合做粗略距离分档和控制增益补偿。

### 局限

- 目标倾斜会使投影面积变小，造成距离高估。
- 相机畸变和角点误差会影响结果。
- 远距离时目标像素面积小，误差比例明显增大。

如果距离是关键控制量，应进行相机标定、姿态补偿，或使用更可靠的深度测量方法。

---

## 3.6 安装偏差补偿与误差计算

相机、激光器或其他执行器的光轴通常不完全重合。可通过标定建立距离与图像偏移之间的关系：

```text
补偿位置 = 插值表(距离)
目标误差 = 补偿位置 − 目标中心
```

### 推荐做法

- 在多个已知距离采集标定点。
- 使用分段线性插值或低阶曲线拟合。
- 分别标定水平和垂直方向。
- 更换镜头、分辨率或安装位置后重新标定。

像素误差可进一步通过像素密度、相机内参或透视校正结果转换为角度误差或物理距离误差。

---

## 3.7 通信帧设计

视觉与控制端之间应使用明确的二进制帧结构，例如：

```text
帧头 + 版本 + 数据长度 + 命令类型 + 有效标志 + 数据区 + 校验
```

### 建议包含的字段

- 协议版本。
- 数据长度。
- 帧序号或时间戳。
- 目标是否有效。
- 误差、距离和置信度。
- CRC 校验。

### 设计原则

- 明确字节序和浮点格式。
- 接收端必须进行长度、范围和校验检查。
- 处理粘包、拆包和丢字节后的重新同步。
- 为协议升级预留版本字段，避免不同程序版本误解析。

# 第四部分：完整算法链路

```text
【视觉端】
相机图像
  → 预处理
  → 规则目标检测
  → 角点排序与透视校正
  → 尺度估计或测距
  → 安装偏差补偿
  → 目标位置误差
  → 通信发送
                  ┐
                  ▼
【运动执行端】    【姿态与决策端】
多路传感器        视觉误差 → 滤波与预测
  → 归一化循迹    自身惯性数据 → 高精度姿态融合
惯性数据          运动状态与任务信息 → 状态机
  → 轻量姿态融合  状态机 → 跟踪目标与动作目标
  → 串级控制      跟踪控制 → 目标姿态
  → 执行机构      目标姿态 → 云台或其他执行机构
```

一句话概括：

> 运动执行端负责快速稳定地运动，视觉端负责从图像中提取目标误差，姿态与决策端负责融合信息并决定当前应该执行什么动作。

# 第五部分：算法迁移到其他硬件平台时的检查清单

## 5.1 与算力有关

- 控制周期内的最坏执行时间是否可接受。
- 矩阵运算、三角函数和图像处理是否需要硬件加速。
- 内存是否足以保存滤波状态、图像缓存和通信缓冲区。
- 算法执行时间是否具有确定性。

## 5.2 与传感器有关

- 量程、单位、坐标轴方向是否一致。
- 采样率和时间戳是否准确。
- 零偏、比例因子和温漂是否重新标定。
- 噪声水平是否需要重新设置滤波参数。

## 5.3 与机械结构有关

- 相机、惯性传感器和执行器安装方向是否变化。
- 轮距、轮径、减速比和负载是否变化。
- 云台传动比、转动惯量和摩擦是否变化。
- 变化后是否重新整定控制器增益和限幅。

## 5.4 与软件接口有关

- 数据类型、单位和字节序是否统一。
- 状态字段是否使用明确枚举。
- 是否保留协议版本、有效标志和 CRC。
- 模块之间是否只传递必要的抽象状态，而不是泄露具体硬件实现。

---

# 第六部分：优先优化建议

1. **将时间型进度估计改为闭环里程估计**：减少速度变化和打滑造成的累计误差。
2. **为目标丢失设计明确策略**：不要把无效数据误当成零误差。
3. **统一变化率限制位置**：避免多层限速造成响应迟钝和调参混乱。
4. **滤波器参数与实际采样率绑定**：采样率改变时自动重新计算系数。
5. **给通信协议增加 CRC、序号和时间戳**：提高抗干扰能力，并便于判断数据新旧。
6. **消除魔数和硬编码阈值**：使用具名参数、枚举和标定表。
7. **优先将像素误差转换为角度误差**：提高算法跨相机、分辨率和镜头迁移能力。
8. **为状态机增加超时和故障恢复**：避免单一传感器异常导致系统卡死。

---

# 总结

整套算法架构最值得保留的不是某个具体硬件型号，而是以下通用设计思想：

- **按算力与实时性进行算法分层。**
- **资源受限端优先使用固定计算量的轻量算法。**
- **高算力端通过更复杂的感知与融合算法换取鲁棒性和精度。**
- **使用状态机将任务决策与底层控制解耦。**
- **通过归一化、滤波、限幅、异常检测和闭环反馈提升工程可靠性。**
- **所有参数都应视为与硬件、采样率、安装方式和场景相关的可标定量。**

因此，在迁移到新平台时，应复用算法结构和数据流，而不是直接沿用原平台的型号、频率、阈值和控制参数。
