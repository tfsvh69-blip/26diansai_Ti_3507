# algo

用于放置 PID、滤波、斜坡、运动学等纯算法。

本层不依赖业务逻辑和硬件寄存器。

## 现有模块

| 文件 | 说明 |
|---|---|
| `pid.h` / `pid.c` | 通用 PID 控制器（P/I/D 独立增益、梯形积分、抗饱和、输出限幅、运行时在线调参） |
| `angle_utils.h` / `angle_utils.c` | 角度差值（最短路径，处理 ±180° 跨界跳变）+ 角度归一化；单位厘度（0.01°） |

## 使用约定

- 算法模块提供**通用接口**（如 `Pid_Init` / `Pid_Update`），各任务通过 `#include` 引用。
- **可调参数**（Kp/Ki/Kd/限幅/阈值等宏）保留在对应任务文件（`app/tasks/taskN.c`）顶部，方便实测时快速改值。
- 不要把与具体赛题逻辑耦合的魔数写进 algo 层。
