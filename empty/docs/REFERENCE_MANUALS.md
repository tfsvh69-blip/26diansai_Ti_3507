维护规则：

- 修改时钟、GPIO、外设复用、中断、低功耗、电气限制前，优先查阅这里的本地手册。
- 改 Emm42 协议帧（`module/emm42/emm42_v5.c`）前，先对照上表的说明书章节确认字节序和语义，不要凭记忆或凭其它工程的代码推断；已核对过的结论沉淀在 [BALL_CONTROL.md](BALL_CONTROL.md) §9.3。
- 若新增芯片资料或版本更新，在本文件同步记录文件名和用途。
- 若手册内容与示例代码或网络资料冲突，以当前芯片对应的数据手册和 TRM 为准。
- ATK-MS6DSV 的 I2C 基础读写流程优先对照正点原子官方例程；当前工程已按其软件 IIC 流程显式处理最后一字节 NACK 和 STOP。
