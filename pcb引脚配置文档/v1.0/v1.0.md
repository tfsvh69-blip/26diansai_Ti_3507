## 3. TMC2209 步进电机驱动

### 3.1 TMC2209 控制信号

| 驱动器 | 功能 | 网络名 | 天猛星引脚 | U2 引脚号 | 连接说明 |
|---|---|---|---:|---:|---|
| U1 | STEP | M1_STEP | B10 | U2.49 | 电机1步进脉冲 |
| U1 | DIR | M1_DIR | B11 | U2.47 | 电机1方向 |
| U4 | STEP | M2_STEP | B06 | U2.25 | 电机2步进脉冲 |
| U4 | DIR | M2_DIR | B07 | U2.26 | 电机2方向 |
| U6 | STEP | M3_STEP | B13 | U2.18 | 电机3步进脉冲 |
| U6 | DIR | M3_DIR | B14 | U2.48 | 电机3方向 |
| U7 | STEP | M4_STEP | B26 | U2.32 | 电机4步进脉冲 |
| U7 | DIR | M4_DIR | B27 | U2.33 | 电机4方向 |
| U1/U4/U6/U7 | ENN | TMC_ENN | A13 | U2.30 | 四路共用使能，低有效 |
| U1/U4/U6/U7 | MS1 | TMC_MS1 | B08 | U2.27 | 四路共用细分配置 |
| U1/U4/U6/U7 | MS2 | TMC_MS2 | B09 | U2.28 | 四路共用细分配置 |

### 3.2 TMC2209 电源与未用脚

| 引脚 / 网络 | 当前连接 | 说明 |
|---|---|---|
| VM | 4S | 电机主电源 |
| VDD / VIO | 3V3 | 当前网表中 U1/U4/U6/U7 的 VDD 均接 3V3 |
| GND | GND | 与开发板、扩展板共地 |
| PDN | 未接 | 不使用 TMC2209 UART 配置 |
| USART | 未接 | 不使用 TMC2209 UART 配置 |
| CLK | 未接 | 使用芯片内部时钟 / 模块默认配置 |
| NC | 未接 | 保持不接 |

### 3.3 细分配置

MS1 和 MS2 由软件控制，不加外部默认上下拉。

| MS1 | MS2 | 细分模式 |
|---|---|---|
| 0 | 0 | 1/8 |
| 1 | 1 | 1/16 |
| 1 | 0 | 1/32 |
| 0 | 1 | 1/64 |

### 3.4 软件初始化建议

上电后建议按以下顺序初始化，避免电机误动作：

| 顺序 | 操作 |
|---:|---|
| 1 | 将 `TMC_ENN` 配置为 GPIO 输出高电平，先禁用四个 TMC2209 |
| 2 | 将 `M1_STEP`、`M2_STEP`、`M3_STEP`、`M4_STEP` 配置为低电平输出 |
| 3 | 将 `M1_DIR`、`M2_DIR`、`M3_DIR`、`M4_DIR` 配置为确定方向 |
| 4 | 将 `TMC_MS1`、`TMC_MS2` 配置为目标细分电平 |
| 5 | 配置四路 STEP 定时器输出 |
| 6 | 最后将 `TMC_ENN` 拉低，使能四个驱动 |

## 9. 电源网络

| 网络名 | 用途 | 当前连接 |
|---|---|---|
| 4S | 电池主电源 / TMC2209 VM / XL4015 输入 | CN1 经开关与保险丝后输出 |
| +5V | XL4015 输出 / 舵机 / 循迹 / 激光测距 / 蜂鸣器 / IMU / 备用串口供电 | 当前与天猛星 5V 引脚相连 |
| 3V3 | 天猛星 3.3V / TMC2209 VDD / 电源排针 H2 | 由天猛星提供 |
| GND | 系统公共地 | 所有模块共地 |

注意：当前网表中天猛星 5V 与扩展板 `+5V` 为同一网络。使用树莓派 USB 给天猛星供电，同时扩展板 XL4015 输出 5V 时，需要接受 5V 并联/反灌风险；如需隔离，可在 PCB 上改为跳帽或 0Ω 选择连接。

## 11. PCB 绘制注意事项

| 模块 | 注意事项 |
|---|---|
| TMC2209 VM / 4S | 主电源线加粗，四路驱动附近放足够铜皮和过孔 |
| 步进电机接口 | 丝印明确标注 `1A / 1B / 2A / 2B` 或 `A+ / A- / B+ / B-` |
| 舵机 5V | 走线加粗，舵机接口附近预留大电容位置 |
| XL4015 | 电感、肖特基、输入输出电容靠近芯片，开关节点铜皮不要过大 |
| IMU | 远离电感、电机驱动和大电流走线 |
| I2C | SDA/SCL 尽量短，必要时预留 4.7k 上拉位 |
| 串口接口 | H20/H21 丝印写明“与激光测距共用” |
| 5V 电源 | 若保留硬并，注意树莓派 USB 与扩展板 5V 的上电顺序 |
| GND | 所有模块必须共地，电机大电流回流尽量不要穿过 IMU / I2C 区域 |
