# 机器人主控板 接线与配置说明

> 主控：立创·天猛星 MSPM0G3507 开发板（LCKFB-TMX-MSPM0G3507）
> 原理图版本：v1.1 / 2026-07-10
> 本文档基于 `Netlist_Schematic1_1_2026-07-10.net` 逐网络核对生成

---

## 1. 系统概览

```
                    XT60 (4S 锂电 14.8~16.8V)
                              │
                        SW1 电源开关 → Q1(AOD4185) → F3(15A)
                              │
                    ┌─────────┴──────────┐
                  4S 总线            XL4015 → +5V ─┬─ 开发板 5V
                    │                              ├─ 4× 舵机
        ┌───────────┼──────────┐                   ├─ 灰度模块 (H6)
   4× TMC2209   2× 张大头     H3                   ├─ 2× 激光测距
   (STEP/DIR)   (UART1)     4S 排针                └─ 蜂鸣器 / 继电器
        │            │
   4× 步进电机   Emm42_V5.0
```

**通信资源分配**

| 外设 | MCU 引脚 | 用途 | 引出位置 |
|---|---|---|---|
| UART0 | PA10 / PA11 | 板载 Type-C 调试串口 | 板载，不外引 |
| UART1 | PA17(TX) / PB5(RX) | 张大头 Emm42_V5.0 ×2 | **H7** |
| UART2 | PB15(TX) / PB16(RX) | 激光测距 1 | **H21** |
| UART3 | PA26(TX) / PA25(RX) | 激光测距 2 | **H20** |
| I2C1 | PB2(SCL) / PB3(SDA) | 六轴 IMU (MS6DSV) | 板载 |

| **F3** | — | 15A 自恢复保险丝，位于 Q1 之后 |

### 3.2 电源排针（均为 4P 直插）

| 器件 | 电压 | 说明 |
|---|---|---|
| **H1** | GND ×4 | |
| **H5** | GND ×4 | |

### 3.3 串口排针（脚序统一）

**H7 / H20 / H21 脚序一致**，方便复用同一根杜邦线：

| 脚 | 定义 |
|---|---|
| 1 | +5V |
| 2 | GND |
| 3 | **MCU RX**（接对端设备的 TX） |
| 4 | **MCU TX**（接对端设备的 RX） |

| 排针 | 串口 | MCU RX (脚3) | MCU TX (脚4) | 并联设备 |
|---|---|---|---|---|
| **H7** | UART1 | PB5 | PA17 | Motor1 / Motor2 |
| **H21** | UART2 | PB16 | PB15 | 激光测距1 |
| **H20** | UART3 | PA25 | PA26 | 激光测距2 |

> ⚠️ 三个排针都与板载设备**并联在同一条总线**上。插 USB-TTL / OpenMV 时，必须先拔掉对应的板载设备，否则两个 TX 会互相顶。

### 3.4 张大头闭环驱动接口（Motor1 / Motor2，KH-A2504-08A 8P）

| 脚 | 网络 | 说明 |
|---|---|---|
| 1 | `USART1_RX` | 驱动器 TX → MCU PB5 |
| 2 | `USART1_TX` | 驱动器 RX ← MCU PA17 |
| 3~6 | NC | 预留 |
| 7 | GND | |
| 8 | 4S | 驱动器电源（Emm42_V5.0 支持 12~36V） |

**驱动器菜单设置**

| 菜单项 | Motor1 | Motor2 |
|---|---|---|
| `Mode` | `CR_UART` | `CR_UART` |
| `UartAddr` | `1` | `2` |
| `UartBaud` | 与 MCU 一致（默认 38400） | 同左 |

> 地址 `0` 为广播地址；广播时只有地址 1 的驱动器会回帧。
>
> 🔴 **接线前请务必对着 Emm42_V5.0 实物丝印确认 pin1/pin2 的 TX/RX 归属**，本板的 8P 连接器符号非官方。

### 3.5 步进电机接口（U10 / U5 / U9 / U8，PH2.0-6P）

四个接口定义完全相同：

| 脚 | 线圈 | 说明 |
|---|---|---|
| 1 | **2B** | B 相 |
| 2 | NC | |
| 3 | **1B** | A 相 |
| 4 | **2A** | B 相 |
| 5 | NC | |
| 6 | **1A** | A 相 |

对应关系：`U10 → M1(U1)`、`U5 → M2(U4)`、`U9 → M3(U6)`、`U8 → M4(U7)`

## 4. SysConfig / 定时器配置

| 功能 | 引脚 | 定时器通道 | PINCM.PF |
|---|---|---|---|
| SERVO1 | PA8 | `TIMA0_C0` | 5 |
| SERVO2 | PA9 | `TIMA0_C1` | 5 |
| SERVO3 | PB4 | `TIMA0_C2` | 5 |
| SERVO4 | PA12 | `TIMA0_C3` | 6 |
| M1_STEP | PB10 | `TIMG0_C0` | 2 |
| M2_STEP | PB6 | `TIMG8_C0` | 5 |
| M3_STEP | PB13 | `TIMG12_C0` | 4 |
| M4_STEP | PB26 | **`TIMG6_C0`** | 5 |

**普通 GPIO（无需定时器）**

| 功能 | 引脚 | 模式 |
|---|---|---|
| BUZZER_CTRL | PA15 | 推挽输出，有源蜂鸣器仅需高/低电平驱动 |
| TMC_MS1 | PB0 | 推挽输出 |
| TMC_MS2 | PB1 | 推挽输出 |
| TMC_ENN | PA13 | 推挽输出（建议外部 10kΩ 上拉，见风险 R4） |
| RELAY | PA24 | 推挽输出 |

**要点**

- 四路舵机共用 `TIMA0` 一个 50Hz 时基（C0~C3），四路 STEP 各占独立定时器，可跑不同频率。
- `TIMG12` 是 32 位定时器，适合分配给需要最宽频率范围的轴。
- `TIMG8` 是全片唯一支持 QEI 的定时器，此处被 M2_STEP 占用。本设计的编码器反馈在 TMC/Emm42 内部闭环，MCU 不读编码器，故不受影响。
- 蜂鸣器改为普通 GPIO 后，**`TIMA1` 整颗定时器完全空闲**（原来担心的 `BUZZER` 与 `M4_STEP` 抢 `TIMA1_C0` 的问题也就不存在了），可留给后续扩展（如需要额外 PWM 或输入捕获）。
- `TIMG7` 同样空闲。

**串口配置**

| 串口 | TX | RX | 建议波特率 |
|---|---|---|---|
| UART0 | PA10 (PF2) | PA11 (PF2) | 115200（调试 printf） |
| UART1 | PA17 (PF2) | PB5 (PF2) | 38400（张大头默认） |
| UART2 | PB15 (PF2) | PB16 (PF2) | 依激光模块 |
| UART3 | PA26 (PF2) | PA25 (PF2) | 依激光模块 |

**I2C1**：PB2 (SCL, PF4) / PB3 (SDA, PF4)，外部 4.7kΩ 上拉，标准/快速模式均可。

## 5. 上电检查清单

**第一次上电前（不插任何模块、不插电池）**

1. 万用表通断档量 `4S` ↔ `GND`、`+5V` ↔ `GND`、`3V3` ↔ `GND`，确认无短路。
2. 确认 XT60 极性：CN1-2 = BAT+，CN1-1 = GND。
3. 确认 D1 (MBR2045CT) 极性：K 接 SW 节点，A 接 GND。
4. 确认 C11 / C3 / C4 电解电容极性。

**空载上电（只插电池，不插 Type-C）**

5. SW1 拨到 ON，量 `+5V` 排针（H4）应为 **5.0 ± 0.1V**。
   - 若偏差大，检查 R7(10k) / R10(3.3k) 分压：`Vout = 1.25 × (1 + R7/R10)`。
6. 量 `3V3` 排针（H2）应为 3.3V。
7. 摸一下 XL4015 和 D1 的温度，空载不应发烫。

**逐模块接入**

8. **先烧一个把 `TMC_ENN`(PA13) 拉高的空程序再插 TMC2209**，避免上电瞬间四片驱动随机使能。
9. 插 TMC2209，量各驱动的 VM ≈ 电池电压、VDD = 3.3V。用板载电位器把电流设到电机额定值的 70% 左右。
10. **插步进电机前先量线圈**，确认 A 相 / B 相配对，再对照 3.5 节压端子。
11. 舵机逐个接入，观察 5V 是否跌落（见风险 R5）。
12. **灰度模块接入前必须先量其输出电平**（见风险 R2）。

**串口调试**

13. 张大头驱动器先单独用 USB-TTL 接 H7 设置好 `Mode` / `UartAddr`，再接回主控。
14. 调试 UART1 时，H7 与 Motor1/Motor2 **不可同时接**。

## 6. 已知风险与待办

| 编号 | 等级 | 问题 | 建议措施 |
|---|---|---|---|
| **R1** | 🔴 P0 | Motor1、Motor2 的 TX **并联**在 PB5 上。Emm42 的 TTL TX 是推挽输出，被寻址方拉低时，另一方仍驱动高电平 → PMOS 对 NMOS 硬灌 | 每路 TX 串一颗肖特基做线与（**BAT54S**，SOT-23 双管正好两路，阴极朝驱动），总线加 **4.7kΩ 上拉到 3V3**。Vf≈0.3V，低电平 0.3V < VIL(0.99V)，余量足够。用 1N4148 (Vf 0.7V) 余量不足，不推荐 |
| **R2** | 🔴 P0 | 灰度模块由 +5V 供电（H6-1），8 路信号直连 PB17~PB24。MSPM0G3507 **只有 PA0/PA1 是 5V 容忍**，PBx 全部不是 | 三选一：① 灰度改供 3V3（先量比较器输出电平）；② 8 路各串 10k + 20k 分压；③ 加一片 74LVC245（3V3 供电、输入 5V 容忍）。**同时要量两个激光模块的 TX 输出电平**，若为 5V，PB16 / PA25 同样中招 |
| **R3** | 🔴 P0 | `+5V` 网络同时接 XL4015 输出和开发板 5V 排针（U2-24/40/42/58）。插电池调试时再插 Type-C，两个 5V 源会对灌 | XL4015 输出到开发板 5V 脚之间串一颗 **SS54**（压降 0.4V，5V→4.6V，板载 LDO 仍够用）；至少在丝印警示"电池与 Type-C 不可同时接入" |
| **R4** | 🟡 P1 | `TMC_ENN`(PA13) 上电时是高阻输入，TMC2209 的 EN 内部无上拉 → 四片驱动可能在上电瞬间随机使能 | EN 网络加 **10kΩ 上拉到 3V3**（EN 高 = 关断） |
| **R5** | 🟡 P1 | TMC2209 的 `PDN_UART`(pin4) 悬空 | 加 10kΩ 下拉到 GND，明确禁用 UART 模式并开启待机降流 |
| **R6** | 🟡 P1 | 蜂鸣器（HNB09A03，电磁式感性负载）无续流二极管，Q3 关断时反峰打 C-E 结 | 蜂鸣器两端反并 **1N4148**（阴极接 +5V） |
| **R7** | 🟡 P1 | `RELAY`(PA24) 上电高阻，继电器模块可能误吸合 | 加 **10kΩ 下拉** + 100Ω 串联限流 |
| **R8** | 🟡 P1 | 5V 输出电容 440µF（C3+C4）对舵机浪涌偏小。四路 MG996R 级舵机堵转峰值已超 XL4015 的 5A 上限 | 舵机排针就近加 1000µF 电解 + 10µF/0805 X5R；开发板 5V 入口单独加 470µF。若舵机功率大，考虑从 4S 另开一路降压 |
| **R9** | 🟡 P1 | Q1 (AOD4185) 的 Vgs 上限 ±20V，4S 满电 16.8V，余量仅 3.2V | G-S 之间反并一颗 12V 齐纳（BZT52C12） |
| **R10** | 🟡 P1 | 4S 电池无电压监测，锂电过放一次即报废 | `4S ──100k── PA27 ──10k── GND`，16.8V→1.53V，配 0.1µF 滤波，接 ADC0 通道 A0_0 |
| **R11** | 🟢 P2 | 步进电机接口同相线不相邻，且脚3/脚4 跨相相邻，易接错 | 下一版改为 `1=1A, 2=1B, 3=NC, 4=2A, 5=2B, 6=NC`，丝印标 `A+ A- / B+ B-` |
| **R12** | 🟢 P2 | U10/U5/U9/U8 的符号引脚名残留为 `GND / +3.3V / PB2 / PB14`，原理图上极具误导性 | 改名为 `1A / 1B / 2A / 2B` |
| **R13** | 🟢 P2 | 三个串口排针与板载设备并联，同时插会导致 TX 冲突 | 丝印标注"排针与板载设备二选一" |
| **R14** | 🟢 P2 | 网络名 `LASERx_TX` / `LASERx_RX` 采用模块视角，与 MCU 视角相反 | 建议统一为 `UART2_MCU_TX` 之类，或在原理图上加注释 |

**打样前必须完成**：R1、R2、R3。前两条会烧器件。
**顺手就能加**：R4、R6、R7 —— 三颗零件加起来不到五分钱。
